Retail Sales Data Cleanup

Overview

A practical data cleaning and analysis project focused on transforming raw retail sales data into a cleaner, more usable dataset for business analysis.

Problem

Raw business data can contain inconsistencies, missing values, duplicate records, and formatting issues that make analysis difficult.

What I Did

- Cleaned and organized the dataset
- Identified and handled data inconsistencies
- Prepared the data for analysis
- Created an Excel-based analysis
- Extracted useful business insights
